# Fidra 0.1.31 — Local Sync candidate

This is a build and acceptance candidate. It is not ready for the stable updater
or installation over a live shared ledger. Existing Local Sync groups require a
reviewed upgrade and coordinated peer cutover before adopting protocol v2.

- Detect missing or replaced mailbox roots without recreating them.
- Retain encrypted exports locally and retry exact bytes after transport failures.
- Preserve financial conflicts for explicit review, including unequal-version
  offline edits, deletions and linked transfers.
- Authenticate exact peer receipt reports and distinguish them from cloud upload
  or current convergence.
- Encrypt attachment contents and descriptive filenames; retain retry copies.
- Restrict immutable snapshots to staged onboarding with accepted causal history.

The candidate workflow builds installers on isolated macOS and Windows runners.
It has no permission to publish releases. Stable publication is explicitly
blocked while `release-candidate.json` records outstanding recovery/cutover gates.

Live account files and mailboxes are not migrated by preparing this candidate.
