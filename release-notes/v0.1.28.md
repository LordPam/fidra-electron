Fidra 0.1.28 adds approved AI sheet creation and fixes income import status.

- AI apps can create empty Fidra sheets through the same controls as Manage Sheets. Names, duplicate checks, sorting and live user permissions are enforced inside Fidra.
- Sheet creation requires explicit sheet-management permission and all-current-and-future-account approval. Existing connection permissions remain unchanged. Passwords and approval stay in native Fidra.
- Retried requests cannot create duplicate sheets or recreate sheets after Undo/deletion. Fidra shows a creation notice and supports native Undo/Redo while the sheet remains empty and unchanged.
- Statement imports now use native transaction defaults: income has no approval status, while expenses start pending. Existing transactions are untouched.

General AI rename/merge/deletion/reordering, linked internal-transfer changes and other ledger editing tools remain in development. This release does not rebuild an existing statement import or move any bank funds.

Update through Fidra Settings → Updates, complete installer replacement and reopen Fidra. Then fully quit and reopen the AI desktop app to refresh the tool list. For sheet creation, revoke the existing narrow connection in Fidra and ask your AI to connect again; approve the matching code with the accounts and permissions you choose. Empty-sheet creation needs no bank statement.
