Fidra 0.1.26 expands approved AI access and improves shared application safeguards.

- New opt-in tools read transactions, planned payments, invoices, categories, activities, supported settings, team roles, sync status and backups. Approved connections can also create backups and run existing sync.
- Existing AI permissions remain unchanged. Additional accounts, fields and actions require a fresh review in Fidra. Passwords and access approval stay inside Fidra.
- On this Mac's previously repaired local helper installation, opening the updated Fidra app refreshes its adapter and tool list automatically. The runtime, saved installation identity and native approvals stay in place. Restart the AI desktop app afterwards. Ordinary account plugin updates remain separate.
- Database shutdown now releases the sync extension before closing SQLite, including failed initialization and backup restore; sync filenames reject both platform path separators.
- Shared application services now enforce the signed-in user's authority and strengthen linked-transfer, activity Undo and backup safeguards.

General AI tools for creating/editing/deleting plans, transfers, sheets, categories, activities and invoices, and the remaining app administration workflows, are still in development. This release does not expose those unfinished operations.

Update on macOS: open Fidra Settings → Updates → Check for updates, download, open the installer, replace Fidra in Applications, then reopen Fidra. Quit and reopen the AI desktop app. Unlock AI access in Fidra if it is paused. To enable additional tools for an existing connection, revoke its existing access and approve a new matching-code request with the accounts and permissions you choose.

The app is distributed without publisher notarization/signing, as in the current release policy. Signed update metadata authenticates installer downloads.
